# Defensive Spread Optimizer

Defensive Spread Optimizer is a macOS desktop application for finding efficient defensive stat spreads for competitive Pokémon.

## How It Works

The application distributes the available investment points between:

- HP
- Defense
- Special Defense

It evaluates how much damage the Pokémon would take from:

- one physical attack
- one special attack of the same power

The optimizer searches through all legal defensive spreads and selects the combination that minimizes the combined damage from both attacks.

This helps create a balanced defensive spread instead of investing only in physical or special bulk.

## Features

- Optimizes HP, Defense, and Special Defense investments
- Compares physical and special damage
- Supports fixed Attack, Special Attack, and Speed investments
- Selectable increased and decreased nature stats
- Displays base stats, final stats, and invested points
- Supports English and German Pokémon names
- Simple desktop interface
